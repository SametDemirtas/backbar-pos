The switch says what it is

A plain toggle makes the manager remember which way is on. This one carries its own label, so "is the Guinness off?" can be answered at arm's length with the phone in one hand.

The tap shows at once

The switch shows a pending state from the tap until the list shows the new value. If the write fails, the row goes back and says why, so a manager never thinks a line is off when it is still selling.

Sold out is not hidden

The same three signals as the till (hatch, struck price and label), so the manager sees what is off as quickly as what is on. Sold-out items stay in the list rather than in a separate tab, where they tend to be forgotten.
